# Проверка в игре со светом: оболочка комнаты + 3 предмета

Для чата игры (`mrbobsterx-boop/godot`). Делаем ОТДЕЛЬНУЮ тестовую сцену, основную игру не меняем.

## Что здесь

У каждой картинки пара: `<имя>.png` — чистый цвет (без света и теней), `<имя>_n.png` — карта нормалей
(R вправо, G вверх, B на камеру — формат OpenGL; проверено в Godot 4.4). Рендер вдвое крупнее игры: **масштаб 0.5**.

| Файл | Что | Размер в игре |
|---|---|---|
| `shelter_living_concrete_normal_mid` | стена + пол комнаты, **бесшовный** — повторять по ширине | 512 × 364 |
| `shelter_living_concrete_normal_left` / `_right` | срез боковых стен (снаружи комнаты слева/справа) | 50 × 364 |
| `slab_bunker_concrete_normal` | перекрытие, **бесшовное**, рисуется ПОВЕРХ верха оболочки | 512 × 100 |
| `locker_metal_armeyskiy_idle` | шкафчик армейский | 52 × 190 |
| `table_wood_pismennyy_idle` | письменный стол с тумбой | 120 × 88 |
| `bed_single_derevyannaya_samodelnaya_idle` | кровать | 201 × 79 |

## Как расставить (в пикселях игры, 1 м = 100 px)

- **Линия пола** — передний край пола комнаты. Низ оболочки, краёв = линия пола.
- Края: левый — правым краем к левому краю комнаты, правый — левым краем к правому.
- Перекрытие: от 300 до 400 px над линией пола (закрывает верх стены — так задумано); ещё одно — от 0 до −100 (пол).
- Предметы: **низ картинки по центру** в точке `x = левый край комнаты + x_m·100`, `y = линия пола − bottom_m·100`.
  Порядок рисования — как в `layout.json` (сзади вперёд):

| Картинка | x_m | bottom_m |
|---|---|---|
| `locker_metal_armeyskiy_idle` | 0.36 | 0.539 |
| `table_wood_pismennyy_idle` | 1.45 | 0.507 |
| `bed_single_derevyannaya_samodelnaya_idle` | 3.95 | 0.44 |

## Свет

`Sprite2D` → `texture` = `CanvasTexture` (`diffuse` = картинка, `normal_texture` = `_n`). `CanvasModulate` тёмный
(~0.2), `PointLight2D` тёплый (≈ 1.0, 0.72, 0.42), `height` 100–150, у лампы под потолком. Тени/свечение — по вкусу.
Готовый образец всей сцены — `godot_test/room_demo/room.gd` (≈ 80 строк), снимок —
`renders/_review/room_shelter_living_workshop_godot.png`.
