# Модели для игры «Shelter»

Здесь готовятся **3D-модели** для игры про выживание в бункере после катастрофы.
Игра — **[mrbobsterx-boop/godot](https://github.com/mrbobsterx-boop/godot)** (Godot 4.7). Данные объектов (что есть
в игре, размеры, варианты) — **Object Constructor (ОС)**: [mrbobsterx-boop/object-constructor](https://github.com/mrbobsterx-boop/object-constructor).

**Что делать сейчас — по шагам: [`STEPS.md`](STEPS.md). Все правила работы с моделями — [`docs/TRIPO.md`](docs/TRIPO.md).**

## Как это устроено (решение автора 2026-10-09)

- Игра показывает мир **в настоящем 3D**, как Fallout Shelter: бункер в разрезе, вид сбоку, живой свет и тени.
  Логика игры — прежняя; 3D-показ уже работает (клавиша V в игре — 3D / 2D).
- Модели делает **автор в Tripo** (платный тариф) из своих картинок ОС — они все в одном стиле.
- Этот репозиторий их **обрабатывает** (размер, поворот, облегчение, текстуры) и отдаёт в игру.

```
картинка ОС ──► Tripo (автор) ──► tripo/<id>_<вариант>.glb ──► обработка (чат моделей)
                                  ──► export/<id>_<вариант>_idle.glb ──► игра: assets/models/ (чат игры)
```

## Главные правила модели

1. **1 единица = 1 метр**, высота — из ОС (`docs/plan.json`, `docs/OBJECTS.md`).
2. **Перед — к −Y** в Blender (в игре — к зрителю), **точка опоры внизу по центру** на полу. Висящее на стене — спиной
   в плоскости Y = 0; потолочное — верхом в Z = 0.
3. **Треугольники:** мелкое ≤ 3 000, мебель ≤ 8 000, крупное ≤ 15 000. Текстуры 1024 (мелкое — 512). Без блеска.
4. **Имя:** `<id>_<вариант>_idle.glb` — id и вариант как в плане ОС (`docs/PLAN.md`).
5. **Только обычный вид.** Сломанное, открытое, «занято» — показывает игра.
6. **Одна вещь — одна модель.** Рюкзак на кровати, ящики под ней — отдельные предметы игры, к модели не прирастают.
7. Свет, тени, туман, время суток, погода — делает **игра**, в модель их не запекать («Удалить освещение» в Tripo).

## Структура

```
docs/TRIPO.md        — главный документ: кто что делает, настройки Tripo, обработка, передача в игру
docs/plan.json       — план объектов ОС (id, варианты, размеры); docs/PLAN.md — чек-лист готовности
docs/OBJECTS.md      — все объекты игры и размеры
docs/DEVIATIONS.md   — где размер модели отличается от ОС и почему
docs/TRIPO_REPORT.md — отчёт обработки (появится после первого запуска)
docs/FOR_GAME.md     — что нужно поменять в игре для моделей
docs/LOG.md          — журнал изменений
tripo/               — сюда автор кладёт GLB из Tripo
export/              — готовые модели для игры
tools/               — tripo_process.py (обработка), sync_plan.js, plan_status.py
layouts/             — расстановки комнат (пока не используются игрой)
archive/             — старый путь (low-poly модели скриптом, рендеры, палитра, правила картинок) — только для справки
```
