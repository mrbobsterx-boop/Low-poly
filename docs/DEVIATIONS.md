# Отклонения от размера ОС (по природе варианта)

В плане ОС один размер на объект, а варианты бывают разные по природе. Где вариант явно не может быть такого размера,
он сделан «как в жизни». **Решение автора (2026-10-08): «сам реши» — отклонения по природе варианта принимаются**;
если нужно иначе — задать размер варианта в ОС и пересобрать модель.
