# Модели из Tripo → игра (главный путь с 2026-10-09)

**Решение автора:** игра показывает мир в **настоящем 3D** (путь Б из README, как Fallout Shelter: бункер в разрезе,
вид сбоку). Модели делает **автор в Tripo** (платный тариф) по образцу (кровать-образец, `docs/TRIPO_OBJECTS.md`). **Рендеры в картинки, карты
нормалей, палитра и скриптовые модели больше не нужны** — модель `.glb` идёт прямо в игру.

Старый путь (рендеры, нормали, палитра, скриптовые модели) и проба стиля удалены 2026-10-10 (есть в истории git).

## Кто что делает

| Кто | Что |
|---|---|
| **Автор** | Делает в Tripo картинку по образцу (кровать-образец) → 3D-модель по запросам из `docs/TRIPO_OBJECTS.md` → скачивает **GLB** → кладёт на Google Диск в папку раздела |
| **Этот чат (обработка)** | Скачивает с Диска (`tools/drive_fetch.py --folder`), обрабатывает скриптом в Blender: поворот, точка опоры, размер из ОС, облегчение сетки, текстуры, матовость → `export/<id>_<вариант>_idle.glb` + лист превью + отчёт |
| **Чат игры** | Забирает `export/*.glb` в игру (`assets/models/`), игра ставит их сама по имени |

Почему обработка нужна: из Tripo модель приходит **тяжёлой** (40–100 тыс. треугольников), **без размера**, **повёрнутой
вбок**, с точкой опоры в центре и 2K-текстурами. Всё это правится автоматически, один раз, для всех моделей.

## 1. Стиль и что делает автор (решение автора 2026-10-10)

- **Стиль один на всех — «кровать-образец»:** low poly, нарисованные цвета, простые формы, матовые поверхности.
  **Объекты разные:** у каждого свои цвета и материалы, ржавчина и потёртости — только где уместно.
- **Как:** в Tripo загрузить картинку кровати-образца → ✏️ → запрос «Replace the bed with …» из `docs/TRIPO_OBJECTS.md`
  → картинка предмета в том же стиле → «Создать» (HD модель) → GLB.
- **Имя файла:** как в `TRIPO_OBJECTS.md` — `<id>_<вариант>.glb` (id и вариант по плану ОС). Один вариант на объект.
- **Куда:** Google Диск «Shelter Tripo» → папка раздела (05 Мебель, 06 Верстаки, …).

## 1а. Где лежат сырые модели

Сырые GLB **в git не кладём** — они на Google Диске автора, папка «Shelter Tripo» (доступ по ссылке — чтение):
https://drive.google.com/drive/folders/1WS4lqCjsxTzgIn6uyvNmC9SVGttSojOb (папки разделов — в `README.md`).
**Скачать раздел:** `python3 tools/drive_fetch.py --folder <id папки> tripo/` (id — из ссылки на папку; `README.md`)
→ файлы в `tripo/` (в git не попадают, `.gitignore`), дальше — обычная обработка. В репозиторий идут только `export/`.
Имя файла на Диске не по плану (как скачал из Tripo) — посмотреть модель и переименовать по `TRIPO_OBJECTS.md`.

## 2. Обработка (этот чат) — скрипт `tools/tripo_process.py`

Запуск: `python3 tools/tripo_process.py` — обрабатывает всё новое в `tripo/` (уже готовое в `export/` пропускает,
`--force` — заново). Для каждой модели:

1. **Импорт** GLB, все части — в один объект, применить трансформации.
2. **Поворот:** «перед» к камере — к **−Y** в Blender (в игре это +Z, к зрителю). Tripo обычно ставит перед к −Y;
   если нет — поправка в `tripo/rotate.json` (`{"bed_single_zheleznaya_koyka": 90}` — градусы вокруг вертикали).
   Проверка — по листу превью.
3. **Точка опоры** — внизу по центру, на полу (Z = 0). Висящее на стене (полки, плакаты, щиты) — спина в плоскости
   Y = 0; потолочное (лампы) — верх в Z = 0, висит вниз (список — `custom.mount` в ОС / ряд `ceiling`).
4. **Размер — из ОС:** высота = `real_height_cm` (`docs/plan.json`, поле `size` = [ширина, высота] см), пропорции —
   как у модели. Ширина отличается от ОС больше чем на 15 % — строка в `docs/DEVIATIONS.md` (решаю сам, автору — список).

**Правило размера (решение автора 2026-10-10):** длинная мебель — кровати, верстаки, столы разборки, швейные столы,
ванна, медицинская койка, кухонная стойка (и всё, у чего ширина ≥ 1,65 высоты) — подгоняется **по ширине** из ОС,
высота — по пропорциям модели (изголовье, щит с инструментами выше — это нормально). Остальное — **по высоте**.
Так же ставит игра (`View3D.model_scale`, список — `godot/data/config/view3d.json` → `fit_width`).
5. **Облегчить сетку** (Decimate, с сохранением UV): мелкий предмет ≤ **3 000** треугольников, мебель ≤ **8 000**,
   крупное (машина, шкаф, станок) ≤ **15 000**. Силуэт должен остаться — проверка на превью.
6. **Текстуры:** уменьшить до **1024** (мелочь — 512); оставить цвет и нормали; **металличность → 0, шероховатость ≥ 0,7**
   (без блеска — свет даёт игра). Общий цветовой фильтр (насыщенность / контраст) — одной настройкой
   `tripo/color.json`, сначала показать автору на 3 моделях.
7. **Экспорт** `export/<id>_<вариант>_idle.glb` (glTF 2.0, +Y up, текстуры внутри), файл ≤ 3 МБ.
   Имя без варианта (`<id>.glb`) → вариант — первый не пропущенный из плана.
8. **Отчёт** `docs/TRIPO_REPORT.md`: имя, треугольники до / после, размер, поворот, предупреждения
   (приросшие лишние вещи, «дыры», не нашёлся id в плане). **Лист превью** `renders/_review/tripo_<дата>.png`:
   каждая модель со светом (тёмный фон, тёплая лампа сверху-сбоку), спереди и в три четверти, подпись.
9. Строка в `docs/LOG.md`, галочка в `docs/PLAN.md` (`python3 tools/plan_status.py`).

Как скрипт решает сам (можно поправить): **класс** по размеру из ОС — высота ≥ 1,5 м или техника/постройка →
«крупное» (15 000); ширина и высота < 55 см → «мелкое» (3 000, текстуры 512); остальное — «мебель» (8 000).
**Крепление** — `mount` в `docs/plan.json` (выгружается из `custom.mount` ОС; стена: спина в Y = 0, низ в Z = 0).
**Цветовой фильтр** `tripo/color.json`: `saturation`, `contrast`, `brightness` (1 — без изменений), `warmth`
(+ теплее / − холоднее); применяется ко всем, только когда `"approved": true`; проверка —
`python3 tools/tripo_process.py --color-test имя1 имя2 имя3` (лист «до / после», без экспорта).

## 3. Передача в игру

Чат игры копирует `export/*_idle.glb` в `assets/models/` репозитория игры. Игра сама: ищет модель `<id>_<вариант>_idle`
→ любую модель этого объекта → иначе показывает картинку. Ставит модель по размеру из ОС (длинная мебель — по ширине,
остальное — по высоте), перед — к зрителю, низ — на пол. Свет, тени, яркость, время суток — делает игра.

## 4. Порядок

Разделы `docs/TRIPO_OBJECTS.md` по порядку: мебель → верстаки → контейнеры → техника → двери и строительное → улица →
растения → инструменты, оружие, одежда → мелкие предметы → персонажи и существа (им нужен риг — отдельное задание).

## 5. Стены и фасады — из трёх слоёв (потом)

Запросы в `TRIPO_KIT.md` — в старом стиле: перед работой переписать под стиль кровати-образца.


**Главный документ — [`docs/TRIPO_KIT.md`](TRIPO_KIT.md):** каталог всех кусков, имена файлов и готовые запросы для Tripo.
Коротко: стена = **основа** (пустая, `room_<набор>_wall_<N>`) + **линии** через всю стену (`room_line_<имя>`: трубы,
кабель, плинтус) + **декор** (`room_decor_<имя>`: решётка, щиток, окно…). Фасады — так же (`facade_…`).

**Обработка (этот чат):** перед — к −Y, спина — в плоскости Y = 0.
- Основа: высота 3 м, ширина — по пропорциям модели (квадратная — 3 м), толщина 0,3 м; ≤ 4 000 треугольников.
- Линия: настоящий размер (длина как есть, обычно 3 м), низ — в Z = 0, левый конец — в X = 0; ≤ 3 000.
- Декор: размер как в запросе (решётка 0,5 м, окно 1,2 м…), низ — в Z = 0; ≤ 3 000.
- Лист превью: основа — 3 куска подряд + линия поверх + декор рядом.

Старые куски `room_bunker_wall_1…5` (трубы внутри куска — на стыках не совпадают) **больше не используются**:
игра их не берёт. Лежат в `tripo/` и `export/` для справки, можно удалить.
