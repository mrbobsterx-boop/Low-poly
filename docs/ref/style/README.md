# Референсы стиля (от автора)

Главный образец, как должно выглядеть: low-poly с видимыми гранями, тёплый свет ламп внутри бункера, холодный закат
снаружи, подробные предметы (ручки, ящики, банки на полках), чёткие силуэты.

- `final_scene.png` — итоговая сцена: бункер в разрезе (3 этажа), руины города, мост, закат.
- `style_sheet_1.png` — лист: сцена, персонажи, небо, город, мост, завалы, модули бункера, реквизит, трубы.
- (третий лист — комната-мастерская, кровать, стол с ящиками, полки, шкафчики, ящики, трубы — прислан в чат;
  положить сюда файлом `style_sheet_2.png`.)

- **Новые образцы (2026-10-09) — главный ориентир по качеству** (`docs/QUALITY.md`): чистый low-poly, ровные плоскости
  и чёткие рёбра, мягкий переход цвета, тёмное в щелях, потёртости на кромках, яркие акценты (красный, оранжевый, синий),
  ремни, болты, таблички «CAUTION», тёмный фон и тёплые лампы:
  - `props_sheet_1.png` — лист реквизита: койка, стулья, стол с ящиками, шкафчик, стеллаж, ящики, бочка, рюкзак,
    канистра, инструменты, щиток, лестницы, ограждения, лампы, дверь;
  - `room_workshop.png` — комната-мастерская в бункере с этими предметами, тёплый свет лампы и окна;
  - `props_sheet_2.png` — лист: модули бункера (стены с трубами, двери), кровати, шкафчики, стеллажи, сантехника,
    кухня, холодильник, диван, ящики разных цветов, трубы, решётки, полы;
  - `bunker_cutaway.png` — бункер в разрезе: этажи, комнаты разного цвета (синяя, жёлтая, красная), лестницы,
    гирлянды лампочек, таблички, персонажи.

Первая версия пробы («голые коробки») отвергнута автором — так НЕ делать.
