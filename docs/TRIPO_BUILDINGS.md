# Отделка стен, фасады, крыши, витрины, разрушения — запросы для Tripo (2026-10-11)

**Как делать (с телефона):** прикрепи **картинку кровати-образца** → нажми кнопку копирования у нужного запроса → вставь → «Создать».
Запросы — как у всех объектов («Replace the bed with…»), каждый целый. **Без рига.** Файл назови, как написано, и положи
на Диск: отделка, разрушения, декор — **«03 Стены — декор»**; фасады, крыши, витрины, улица — **«04 Фасады»**.

**Три вида** — только у отделки стен, фасадов, крыш и витрин: `_ok` — целое, `_damaged` — испорченное, `_ruined` —
наполовину разрушенное. Остальное — по одному разу. Фасады, крыши и витрины — кусками по 3 м с ровными краями:
игра ставит их рядом и друг на друга. Отделка — квадрат 1 × 1 м, рисунок продолжается во все стороны.
