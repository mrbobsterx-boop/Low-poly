# Какие картинки делать (путь А: рендер в 2D)

Основа — раздел 9 `GAME_MAP.md` игры (требования к картинкам). Здесь — то же, но для рендеров из Blender.
Всё, что не подходит под эти правила, в игру не встанет или встанет криво.

## 0. Общее для всех рендеров

| Параметр | Значение |
|---|---|
| Масштаб игры | **1 см = 1 px** (1 м = 100 px). Рендерим **вдвое крупнее: 200 px на метр** |
| Камера | Одна на всех: ортографическая, вид сбоку, наклон сверху **12°** (`render/_template.blend`). Никакой перспективы |
| Свет | **Нет** (правило 10 README): только чистый цвет палитры, цветокоррекция **Standard** |
| Пара файлов | `<имя>.png` — цвет (с прозрачностью) и `<имя>_n.png` — карта нормалей (формат — README, «Для пути А»). Один размер, пиксель в пиксель |
| Фон | Прозрачный (кроме комнат-оболочек и дальних слоёв улицы — там непрозрачно) |
| Направление | Персонажи и животные смотрят **вправо** (влево игра отражает сама). Предметы — «передом» к камере |
| Опора | **Низ картинки = пол / земля.** Ножки стоят ровно на нижнем крае, по центру картинки |
| Поля | Предметы — **без пустых полей** вокруг (обрезать по контуру). Комнаты и фоны — точно по размеру |
| Имена | Латиница, id из игры: `<id>_<вариация>_<состояние>.png` (как в ОС). Пример: `bed_single_wood_idle.png` |
| Куда | `renders/<категория>/…` — дальше автор переносит в ОС (`assets/refs/<категория>/`) и синхронизирует с игрой |

## 1. Предметы, мебель, приборы, хранилища, растения (из ОС)

- **Высота — как в ОС** (`docs/OBJECTS.md`, второе число): шкаф 180 см → 360 px в рендере. Ширину даёт сама модель.
- Состояния: `idle` (обязательно), `broken` (если предмет ломается — в ОС есть «сломанный»), `icon` (иконка для
  инвентаря: **квадрат 256×256**, предмет крупно по центру, та же камера).
- Вариации — по желанию (`wood`, `metal`, `old`…): игра выбирает случайную.
- **Висящее** (лампа, часы, полка, щиток, окно, выключатель): картинка — только сама вещь; где висеть, задаёт ОС
  (`custom.mount` = `wall` / `ceiling`).
- Выше **270 см** в комнату не встанет (под потолком). Уличное — можно выше.
- Ничего лишнего в кадре: без пола под предметом, без стены за ним, без теней.

## 2. Комнаты — «оболочки» (новое, для глубины)

**Комната = пустая коробка + отдельные предметы.** Мебель в комнату **не впекаем**: каждую кровать, шкаф, плиту
человек в игре обыскивает, берёт, переносит, ломает, в них лежат вещи. Поэтому оболочка — только стены, пол,
потолок и «неживой» декор.

- Что в оболочке: задняя стена, видимая полоса пола (наклон 12°), полоса потолка, трубы, кабели, вентиляция,
  трещины, плитка, обои, плакаты, следы протечек — всё, с чем нельзя ничего сделать.
- Что **не** в оболочке: мебель, хранилища, приборы, лампы, двери, окна, лестницы — это предметы ОС (раздел 1).
- Размеры (в игре; рендер ×2):
  - **Сегмент** `<тип>_<вариация>_<состояние>_mid.png` — **512 × 300 см**, бесшовный по горизонтали (игра
    повторяет его на всю ширину комнаты 5–8 м). Низ = линия пола (передний край пола).
  - **Края** `…_left.png` и `…_right.png` — боковые стены коробки, **50 × 300 см**.
  - **Перекрытие** между этажами `slab_bunker_…png`, `slab_house_…png` — **512 × 100 см**, бесшовное (толстая
    рамка разреза: бетон, балки, арматура).
- Типы комнат (как в игре): бункер — `entrance`, `shelter_living`, `kitchen`, `storage`, `workshop`, `water_room`,
  `machine_room`, `greenhouse`; дома — `house_living`, `bedroom`, `kitchen`, `bathroom`, `garage`, `office`, `shop`,
  `medical`.
- Состояния: `normal`, `abandoned` (пыль, паутина), `looted` (сорванные плакаты, мусор у стен),
  `damaged` (пробоины, обломки у стены — без провалов в полу).
- Оболочки **темнее предметов** — иначе вещи теряются на фоне.

**Готовые расстановки (чтобы комнаты были «как задумано», а не случайные).** Можно собрать в Blender полную комнату
с мебелью — но отдать **не картинкой, а списком**: какой предмет (id) где стоит. Файл
`layouts/<тип>_<имя>.json`: `{"room": "kitchen", "width_m": 6, "items": [{"id": "fridge", "x_m": 0.6, "row": "back"}, …]}`
(`x_m` — от левого края, `row` — `back` у стены, `mid`, `front`). Игра расставит по нему настоящие предметы.
Это надо доделать в игре (см. `docs/FOR_GAME.md`).

## 3. Дома снаружи (фасады)

- Фасад дома на улице: ширина **560–860 см**, высота **300–420 см** (1 этаж) / **420–680 см** (2 этажа).
- Файлы: `facade_<тип>_<вариация>_<состояние>.png` — тип `house`, `shop`, `garage`…, состояние как у комнат
  (`normal`, `abandoned`, `looted`, `damaged`).
- Дверь фасада — **по центру** низа (вход), окна — по этажам. Крыша — часть фасада.
- Низ = земля, прозрачный фон.

## 4. Улица: дальние слои (параллакс)

- 3 слоя, **бесшовные** по горизонтали, низ = линия земли, сверху прозрачно; **неба не рисовать** (солнце, луна,
  облака, звёзды — игра):
  - `skyline_1` — дальний город на горизонте, 2048 × 600;
  - `skyline_2` — средний (мост, руины), 2048 × 500;
  - `skyline_3` — ближний (заборы, деревья, завалы), 2048 × 300.
- Дальние слои — светлее и синее (дымка), ближние — темнее и чётче.

## 5. Персонажи и животные

- Кадры анимации — **листом в строку**, все кадры одного размера:
  - человек — кадр **120 × 200 см**, ноги — по центру низа кадра; собака — **120 × 80 см**;
  - `survivor_base_walk.png` (8 кадров), `_idle` (4), `_work` (6), `_sleep` (2), `_sit` (2), `_hit` (4), `_hurt` (2),
    `_die` (6), `_carry` (8) — и к каждому `_n.png`.
- Смотрит **вправо**. Одежда — пока одна базовая (разная одежда на теле — только в пути Б).
- Портрет для экрана «Персонажи» — `portrait_<вариация>.png`, **400 × 500 px**, по пояс, та же палитра
  (здесь допускается лёгкий свет — это интерфейс, не мир).

## 6. Блоки земли (копание)

- `block_<id>.png` — клетка **100 × 100 см**, бесшовная со всех сторон (земля, камень, бетон, кирпич…).
- Вид — срез, ровно спереди (без наклона), плюс `_n.png`.

## 7. Чек-лист перед отдачей

- [ ] Камера из шаблона (наклон 12°), масштаб 200 px/м, высота по ОС.
- [ ] Чистый цвет без света и теней, цвета — только из палитры, Standard.
- [ ] Есть `_n.png` того же размера.
- [ ] Низ = пол, по центру; без полей (предметы) / точно по размеру (комнаты, фоны).
- [ ] Бесшовность (оболочки, перекрытия, слои улицы, блоки).
- [ ] Имя по правилам, файл в `renders/<категория>/`, отметка в `docs/OBJECTS.md`.
