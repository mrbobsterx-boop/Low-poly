# Список объектов игры

Собран из данных игры (Object Constructor → `godot/data/objects/*.json`). **id = имя файла модели** (`models/<категория>/<id>.blend` и `export/<id>.glb`). Размер — ширина × высота в сантиметрах, как в ОС (вид сбоку). Глубину (Y в Блендере) задаёте сами по смыслу.

Колонка «2D» — есть ли сейчас картинка в игре.

Блоки земли/камня для копания (`block_*`) — отдельная тема (тайлы), здесь не перечислены.
