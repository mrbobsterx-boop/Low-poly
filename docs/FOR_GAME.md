# Что нужно поменять в игре для моделей

Сюда записывается, если для моделей нужна правка игры (`mrbobsterx-boop/godot`). Автор перенесёт в чат игры.

- **Общий свет «солнце / небо» по картам нормалей** (путь А; решение автора 2026-10-08). Рендеры — без света
  (правило 10), поэтому в игре нужно: (1) картинки объектов грузить вместе с картой нормалей `<id>_n.png`
  (CanvasTexture: diffuse + normal); (2) направленный свет (DirectionalLight2D) — солнце/луна, угол и цвет по времени
  суток и погоде, под землёй — слабый; (3) общая подсветка неба (CanvasModulate) не должна «съедать» грани.
  Лампы, огонь, фонарь (PointLight2D) уже есть — им включить тени/нормали. Сделает чат игры, когда будут первые рендеры.
- **Глубина комнат: оболочки** (`docs/IMAGES.md`, раздел 2): сегмент 512×300 + края 50×300 + перекрытие 512×100,
  полоса пола (наклон 12°), предметы в 3 ряда (`back` / `mid` / `front`). Сейчас игра понимает только плоскую стену
  `assets/rooms/<тип>.png` 512×300.
- **Готовые расстановки** `layouts/<тип>_<имя>.json` — игра ставит предметы по списку вместо случайной расстановки
  (с проверкой зон и того, что разрешено в комнате).
- **Фасады домов** картинками (`facade_…`), **анимация кадрами** (лист в строку), **иконки** — из картинки `idle` (уменьшить и наклонить кодом; отдельных картинок-иконок не будет).
