# Что нужно поменять в игре для моделей

Сюда записывается, если для моделей нужна правка игры (`mrbobsterx-boop/godot`). Автор перенесёт в чат игры.

**Как игра берёт модели сейчас** (2026-10-09, `scripts/world3d/view3d.gd`):
- файлы `assets/models/<id>_<вариант>_idle.glb` (копия из `export/` этого репозитория);
- ищет вариант объекта → любую модель этого объекта → иначе старая картинка;
- ставит по **высоте из ОС**, низ — на пол, перед (−Y в Blender) — к зрителю; ряд по глубине — по виду вещи;
- лампы на потолке — верх модели у потолка;
- сломанный объект — рассыпается на куски (поломку показывает игра);
- стены — из трёх слоёв (основа, линии, декор), см. `docs/TRIPO_KIT.md`.

Пока просьб нет.

## 2026-10-13 — анимации: рывки и скорость ходьбы

- В `export/anim/*.glb` исправлены рывки: знак поворотов костей скакал между кадрами (q ↔ −q), и движок между кадрами
  крутил кость «длинным путём». Файлы перезаписаны — **переимпортировать**.
- Ходьба, бег, ползание — «на месте». Чтобы ноги не скользили, персонажа нужно двигать с **родной скоростью анимации**
  (или менять скорость проигрывания пропорционально): `export/anim/anims_mixamo_info.json` → `speed_mps`.
  Основные: `walk` 1,77 м/с, `run` 5,43 м/с, `jog` 1,81, `sneak` 0,97, `crawl` 0,47, `injured_walk` 1,18,
  `zombie_walk` 0,32, `zombie_run` 2,85, `mutant_walk` 1,21, `mutant_run` 2,18.
- Переходы между анимациями — плавно (смешивание 0,2–0,3 с), иначе поза «прыгает».
- Анимации уже на скелете тел Tripo — в Godot **не включать** поверх ещё одно перенаправление (Retarget / BoneMap /
  «Rest Fixer»), иначе позы исказятся. Импортировать как есть, проигрывать на `Skeleton3D` персонажа по именам костей.
