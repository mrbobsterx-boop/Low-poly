# Что нужно поменять в игре для моделей

Сюда записывается, если для моделей нужна правка игры (`mrbobsterx-boop/godot`). Автор перенесёт в чат игры.

- ✅ ~~Проверить карту нормалей с лампой~~ — проверено в Godot 4.4 (`renders/_test/godot_lamp_check.png`): формат
  верный, ничего переворачивать не нужно. Готовая тестовая сцена — `godot_test/test_normals/` (CanvasTexture +
  PointLight2D за мышкой) — её можно взять за образец, как подключать `_n.png`.
- **Общий свет «солнце / небо» по картам нормалей** (путь А; решение автора 2026-10-08). Рендеры — без света
  (правило 10), поэтому в игре нужно: (1) картинки объектов грузить вместе с картой нормалей `<id>_n.png`
  (CanvasTexture: diffuse + normal); (2) направленный свет (DirectionalLight2D) — солнце/луна, угол и цвет по времени
  суток и погоде, под землёй — слабый; (3) общая подсветка неба (CanvasModulate) не должна «съедать» грани.
  Лампы, огонь, фонарь (PointLight2D) уже есть — им включить тени/нормали. Сделает чат игры, когда будут первые рендеры.
- **Глубина комнат: оболочки** (`docs/IMAGES.md`, раздел 2): сегмент 512×364 + края 50×364 + перекрытие 512×100,
  полоса пола (наклон 12°), предметы в 3 ряда (`back` / `mid` / `front`). Сейчас игра понимает только плоскую стену
  `assets/rooms/<тип>.png` 512×300.
- **Висящее под потолком** (лампы, `row: ceiling` / `custom.mount = ceiling`): верх картинки — на 300 см от линии
  пола, в любом ряду (иначе прячется за перекрытием). **Персонажи:** линия земли на 3 px выше низа кадра.
- **Образец сборки комнаты** — `render/_mockup.py` + `renders/_test/mockup_shelter_living.png`: порядок рисования
  (оболочка → края → back → mid → front → потолочные → перекрытия) и все сдвиги — как должно быть в игре.
- **Готовые расстановки** `layouts/<имя>.json` (поля: `shell`, `width_m`, `items[]` с `image`, `x_m`, `bottom_m`; порядок =
  порядок рисования). **Готовый образец кода** — `godot_test/room_demo/room.gd` (≈80 строк): оболочка, края, перекрытия,
  предметы по списку, CanvasTexture + PointLight2D. Снимок — `renders/_review/room_shelter_living_workshop_godot.png`. — игра ставит предметы по списку вместо случайной расстановки
  (с проверкой зон и того, что разрешено в комнате).
- **Размер рендера — из самой картинки** (решение автора по пункту 1): ширина и высота в игре = пиксели картинки ÷ 2
  (рендер 200 px/м, игра 100 px/м), а не высота из ОС. Картинка обычно чуть выше числа ОС: видно ещё верх предмета
  (+ глубина × 0,21). Низ картинки = пол, по центру. Автор сделает в игре вместе со светом, когда придут первые рендеры.
- **Стыковка этажей и ряды** (`docs/IMAGES.md`, раздел 2): оболочка 512 × 364, перекрытие 512 × 100 рисуется поверх
  верхних 64 см оболочки (300–400 от края пола), этаж 400. Предметы рядов поднимаются: `front` +11, `mid` +32, `back` +53 px.
- **Фасады домов** картинками (`facade_…`), **анимация кадрами** (лист в строку), **иконки** — из картинки `idle` (уменьшить и наклонить кодом; отдельных картинок-иконок не будет).
