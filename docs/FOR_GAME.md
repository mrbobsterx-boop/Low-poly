# Что нужно поменять в игре для моделей

Сюда записывается, если для моделей нужна правка игры (`mrbobsterx-boop/godot`). Автор перенесёт в чат игры.

**Как игра берёт модели сейчас** (2026-10-09, `scripts/world3d/view3d.gd`):
- файлы `assets/models/<id>_<вариант>_idle.glb` (копия из `export/` этого репозитория);
- ищет вариант объекта → любую модель этого объекта → иначе старая картинка;
- ставит по **высоте из ОС**, низ — на пол, перед (−Y в Blender) — к зрителю, в один ряд у плоскости хода;
- лампы на потолке — верх модели у потолка;
- сломанный объект — наклон модели (позже — своя поломка в игре).

Пока просьб нет. Старые пункты (картинки, карты нормалей, оболочки-картинки) — в `archive/docs/FOR_GAME_old.md`.
