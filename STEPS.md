### Посмотреть самому в Godot (по желанию, ~10 минут)

Для этого есть готовая тестовая сцена — ничего собирать руками не надо. Игру она **не трогает**: делаем отдельный
пустой проект.

**1. Скачать репозиторий**
1. Откройте в браузере: https://github.com/mrbobsterx-boop/Low-poly
2. Зелёная кнопка **«Code»** → **«Download ZIP»**.
3. Найдите скачанный `Low-poly-main.zip` (обычно в «Загрузках») → правой кнопкой → **«Извлечь всё»** → «Извлечь».
   Получится папка `Low-poly-main`.

**2. Создать пустой проект в Godot**
1. Запустите Godot. Откроется **Менеджер проектов** (список проектов).
2. Нажмите **«+ Создать»** (Create).
3. Название проекта: `test_lamp`. Путь — любой, например «Документы». Остальное не трогать.
4. Нажмите **«Создать и редактировать»** (Create & Edit). Откроется пустой редактор.

**3. Положить в проект тестовую сцену**
1. Сверните Godot. В проводнике откройте `Low-poly-main` → `godot_test`.
2. Там папка **`test_normals`** — скопируйте её (выделить → Ctrl+C).
3. Откройте папку проекта `test_lamp` (там лежит файл `project.godot`) → вставьте (Ctrl+V).

**4. Запустить**
1. Вернитесь в Godot. Слева внизу панель **«Файловая система»** (FileSystem) — в ней появится папка `test_normals`
   (если нет — подождите пару секунд).
2. Откройте её и **дважды щёлкните** по `test_normals.tscn` — сцена откроется.
3. Нажмите **F6** (или вверху справа кнопку «Запустить текущую сцену»). Откроется окно с многогранником.
4. **Водите мышкой вокруг многогранника** — лампа ходит за мышкой. Грани со стороны мышки должны светлеть.
5. Закройте окно. Проект `test_lamp` потом можно удалить — для игры он не нужен.

Если что-то выглядит не так (свет «с другой стороны», ошибка при открытии) — напишите, что видите, или пришлите
скриншот.

### Как будет дальше с файлами (для справки)

- **Картинки** (готовые для игры) — `renders/<категория>/…png`. Смотреть — прямо на GitHub или после «Download ZIP».
- **Модели** — `models/<категория>/<id>.blend`: открыть в Blender → **File → Open** → выбрать файл. Сохранять ничего
  не нужно, это просто посмотреть. Для пути Б — `export/…glb`.
- После каждой моей правки — скачайте ZIP заново (старую папку можно удалить).
